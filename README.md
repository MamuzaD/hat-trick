Submit your team and project link, get your odds, bet fake coins, and argue with
the hat in chat. This project always wins. Claude will explain why that's fair.

> Vibecoded w/ Claude for the UNLV Claude Builders Club's workshop contest.
> One of the themes was "solving a problem nobody has."

## Features

- Live odds based on project links, vibes, hat-head fit, and pizza consumption
- A `[ why? ]` button that makes the model defend its obviously fair rankings
- Fake hat-coin bets, receipts, and a trading-floor chat to argue about the results
